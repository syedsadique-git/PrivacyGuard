# AI Agent Prompt: Build PrivacyGuard Website ## Role & Mission You are a senior full-stack engineer and UI/UX designer. Your task is to build **PrivacyGuard** — a centralized privacy dashboard web app that scans user online activities to identify trackers, cookies, and privacy leaks. This is a production-grade MVP, not a prototype. --- ## Product Overview **PrivacyGuard** fills a gap in the privacy tools market: most tracker blockers (Privacy Badger, Ghostery) are browser extensions without a centralized dashboard. PrivacyGuard gives users a web-based command center for their entire digital privacy posture. **Core Value Proposition:** One place to see, understand, and act on every tracker, cookie, and data breach tied to a user's browsing. --- ## Tech Stack (Strict) | Layer | Technology | |---|---| | Frontend | React 18 + Vite, Tailwind CSS, Recharts for data viz | | Backend | Node.js + Express.js | | Database | PostgreSQL (via Prisma ORM) | | Browser Extension | Vanilla JavaScript (Manifest V3) | | Auth | JWT + bcrypt | | Tracker Rules | EasyList / EasyPrivacy filter lists (fetched & parsed) | | Breach Detection | HaveIBeenPwned API (or mock for MVP) | --- ## Visual Design Direction **Aesthetic:** Dark-mode cyber-security dashboard. Think: deep navy and black backgrounds, electric teal/cyan as the primary accent, subtle grid patterns, monospaced fonts for data readouts, sharp geometric UI elements. Inspired by network monitoring tools — functional, data-dense, but visually dramatic. **Key Design Rules:** - Dark backgrounds only (`#050C14`, `#0A1628` range) - Accent colors: electric teal `#00E5CC`, alert red `#FF4D4D`, safe green `#00C853` - Typography: `JetBrains Mono` for data/numbers, `Sora` for headings and body copy - Cards with subtle glowing borders on hover - Animated score rings, pulsing threat indicators - No generic purple gradients. No white backgrounds. No Inter font. --- ## Pages & Features to Build ### 1. Landing Page (`/`) **Purpose:** Convert visitors. } model Tracker { id String @id @default(uuid()) userId String domain String trackerName String category String // Analytics, Advertising, Social, Fingerprinting firstSeen DateTime @default(now()) lastSeen DateTime @default(now()) count Int @default(1) isBlocked Boolean @default(false) user User @relation(fields: [userId], references: [id]) } model Settings { id String @id @default(uuid()) userId String @unique globalBlocking Boolean @default(false) emailAlerts Boolean @default(true) user User @relation(fields: [userId], references: [id]) } enum Plan { FREE PREMIUM } ``` --- ## Browser Extension (Manifest V3) **Files:** `manifest.json`, `background.js`, `content.js`, `popup.html` **Functionality:** - `background.js`: Uses `declarativeNetRequest` API to block URLs matching EasyList/EasyPrivacy filter rules. On each page load, sends detected tracker data to the PrivacyGuard backend API (POST /api/trackers/scan) with the user's auth token. - `content.js`: Reads cookies on the current page and reports them to background script. - `popup.html`: Mini UI showing tracker count for current site, global block toggle, link to open full dashboard. **Auth:** Extension stores JWT in `chrome.storage.local`. User links extension from the onboarding flow. --- ## Privacy Score Algorithm Calculate score server-side and return from `/api/dashboard/summary`: ``` base_score = 100 deductions: - per unique tracker domain (max -30): -1 per tracker, capped - global blocking OFF: -20 - active data breach found: -25 - no extension connected: -15 bonuses: - all trackers blocked: +10 - no breaches: already preserved final_score = clamp(base_score + bonuses - deductions, 0, 100) ``` Score color: 0–39 = red, 40–69 = yellow, 70–100 = green. --- ## MVP Scope (Build First) Focus the initial build on these — everything else can be stubbed: 1. ✅ Landing page (fully polished) 2. ✅ Signup / Login 3. ✅ Dashboard with privacy score, tracker table, breach alert 4. ✅ Trackers page with block toggles 5. ✅ Breaches check (HaveIBeenPwned integration or mock) 6. ✅ Settings page (basic) 7. ✅ Backend API (auth + trackers + dashboard summary + breach check) 8. ✅ Database schema and seed data 9. ✅ Browser extension (basic version — detect + report trackers) Stub for later: Reports page, PDF export, VPN integration, auto-block premium features, full notification system. --- ## Code Quality Standards -
