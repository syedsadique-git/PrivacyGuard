# Extension Icons

Place your extension icons here:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Design Guidelines

- Use the PrivacyGuard shield logo
- Primary color: #00E5CC (cyber-teal)
- Background: Transparent or #050C14 (cyber-dark)
- Style: Minimalist, geometric, cybersecurity aesthetic

## Quick Icon Generation

You can use these tools to generate icons:
- [Figma](https://figma.com)
- [Canva](https://canva.com)
- [GIMP](https://gimp.org)
- [Photopea](https://photopea.com) (online)

Or use a simple SVG-to-PNG converter with the shield SVG from the app.

## Temporary Solution

For development, you can use any placeholder images with the correct dimensions.
The extension will work without icons, but they won't display properly.
